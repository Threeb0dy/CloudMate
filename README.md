让空中课堂的回放，成为可检索、可问答、可追溯的复习资料。

Coursedeck 是面向上海财经大学教学网课程点播的浏览器插件，帮助你通过问答查找课堂内容、梳理知识点，为期末复习节省翻找回放的时间。

> 目前仅适用于 Firefox 火狐浏览器。

## 为什么做 CloudMate？

期末周抱佛脚时，我们常常记得老师提过考试范围、题型或重点，却想不起具体说了什么，更想不起是哪一节课。

可能是时间太久忘了，也可能是~~当时根本没去听课~~。打开空中课堂，回放一节不少，但为了找一句话，还是得反复拖动进度条。遇上思路活跃、知识点穿插讲解的老师，即使倍速刷完，也未必能把内容串起来。

**回放录得完整，并不等于它就容易被用来学习。**

这就是出发点：把课程点播转化为可检索、可问答、可追溯的语料，让你带着问题找内容，也能回到课堂原文核对依据。

## 可以用它做什么？

- **查找课堂内容**：围绕考试范围、题型、考点等信息进行检索。
- **与课程问答**：用自然语言提问，帮助理解和梳理课堂知识点。
- **追溯回答依据**：结合对应的课堂内容核对答案，保留上下文。

复习时，可以试着问：

> 老师有没有提到期末考试的范围和题型？
>
> 这门课反复强调了哪些重要知识点？
>
> 老师是怎么解释这个概念的？举过什么例子？

## 下载与使用

### 方式一：通过网站安装（推荐）

1. 使用 **Firefox 火狐浏览器**打开 [Coursedeck 下载页](https://www.xsufe.com/coursedeck)。
2. 点击页面上的 **「安装到侧边栏」**，按照页面及浏览器提示完成安装。
3. 在 Firefox 侧边栏打开 Coursedeck，按插件内提示开始使用。

### 方式二：直接下载 ZIP

如果你希望下载项目文件，可以在本 GitHub 仓库页面点击 **「Code」→「Download ZIP」**，下载后解压到本地。

此方式下载的是仓库文件；下载完成不代表插件已安装。需要直接使用，请优先通过上方网站入口安装。
